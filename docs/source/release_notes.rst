Documentation
~~~~~~~~~~~~~

* Added a Sphinx documentation site with tutorial, design, API, and release
  note layers.
* Added rendered mathematical explanations for core SDP objects,
  regularization, CVXPY/Optax solver entry points, tomography, Pauli helpers,
  and quantum optimal transport.
* Adopted QOT notation where :math:`\Gamma` is the coupling,
  :math:`\gamma_k` is the :math:`k`-th one-body marginal, and
  :math:`\operatorname{Tr}^k` is the partial trace that keeps subsystem
  :math:`k`.
